Assessment boundaries

This college project performs passive WHOIS/DNS collection, a normal TCP connect scan, response-header inspection, password rule analysis, and optional bounded packet-metadata observation. It does not exploit systems, attempt credentials, inject traffic, evade controls, decrypt traffic, or run destructive commands.
